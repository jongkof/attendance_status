# 처음 비밀번호(환경 변수)를 쓰는 동안 로그인 토큰이 유출되면 비밀번호를 추측당할 수 있다

**Symptom**: 화면에서 비밀번호를 바꾸기 전에는 로그인 토큰의 서명 키가 환경 변수 비밀번호 원문의 SHA-256 값이다. 토큰이 유출되면 빠른 해시라서 비밀번호 후보를 오프라인에서 빠르게 대입해 볼 수 있다.

**Observed evidence**: 코드 리뷰(`code-review low`)가 `lib/admin/credential.ts`의 `sessionSecret`에서 지적했다. 재현은 하지 않았다. 화면에서 비밀번호를 바꾼 뒤에는 scrypt 해시로 서명하므로 해당하지 않는다.

**Suspected cause**: 서명 키를 비밀번호에서 직접 파생해, 비밀번호가 바뀌면 이전 로그인이 무효가 되게 한 설계의 부작용이다.

**What was tried**: 없음. 로그인 토큰은 `httpOnly` 쿠키라 스크립트로 읽을 수 없고, 화면에서 비밀번호를 한 번 바꾸면 사라지는 위험이어서 이번에는 두었다.

**Proposed next step**: 서버에 별도의 임의 서명 키(`ADMIN_SESSION_SECRET`)를 두고, 그 키와 비밀번호 해시(또는 비밀번호 변경 시각)를 함께 섞어 서명 키를 만든다. 그러면 비밀번호가 바뀌면 이전 로그인이 무효가 되는 성질은 유지하면서 토큰으로 비밀번호를 추측할 수 없다.

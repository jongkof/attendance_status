# 팀 잠금 구현 리뷰에서 남긴 두 가지 (수용 기준과 무관)

- 관리자 쿠키 경로를 `/admin`에서 `/`로 바꿨다. 배포 전에 만든 `/admin` 경로 쿠키가 12시간 남아 있는 상태에서 관리자 비밀번호를 바꾸고 다시 로그인하면, `/admin` 요청에 옛 쿠키가 먼저 실려 로그인 화면이 반복될 수 있다. 로그아웃하거나 12시간이 지나면 풀린다. `startSession`이 옛 경로 쿠키도 지우면 해결된다.
- `parseMonth`가 받아 주는 월 형식이 `YYYY-MM`이 아니면(예: `2026-1`) 로그인 뒤 `safeTeamNextPath`가 월을 버리고 이번 달로 보낸다. 현황 메일 링크는 `YYYY-MM`이라 영향이 없다.
